## Что представляет собой программа

Многостраничный корпоративный веб-сайт компании ООО «Климат-Инжиниринг», которая занимается продажей и установкой систем кондиционирования и вентиляции. Сайт работает как интернет-магазин с личным кабинетом, калькулятором стоимости и панелью администратора. Развёрнут на реальном VPS-сервере (Ubuntu 24.04, Apache2, PHP 8, MySQL 8).

---

## Технологический стек

**Фронтенд (клиентская часть):**
- Чистый HTML5, CSS3, JavaScript (ES6+) — без фреймворков
- Chart.js 4.4.0 — графики в панели администратора
- EmailJS — отправка заказов на email
- Адаптивная вёрстка через CSS Grid и Flexbox
- CSS Custom Properties (переменные) для единой дизайн-системы

**Бэкенд (серверная часть):**
- PHP 8 — REST API
- MySQL 8 — база данных
- Apache2 — веб-сервер
- PDO — безопасная работа с БД через подготовленные запросы

## PHP REST API

Все эндпоинты находятся в папке `/api/`, возвращают JSON формата `{"ok": true, "data": ...}` или `{"ok": false, "error": "..."}`. Авторизация через PHP-сессии (cookies). Все запросы к БД используют PDO с подготовленными запросами.

### Авторизация `/api/auth/`

| Метод | Файл | Описание |
|---|---|---|
| POST | register.php | Регистрация, password_hash() |
| POST | login.php | Вход, password_verify(). Логин admin/admin123 → сессия администратора |
| POST | logout.php | Выход, session_destroy() |
| GET | me.php | Текущий пользователь из сессии |
| PUT | profile.php | Обновить имя и телефон |

### Товары `/api/products/`

| Метод | Файл | Описание |
|---|---|---|
| GET | index.php | Список всех товаров |
| POST | store.php | Добавить товар (только admin) |
| PUT | update.php?id=X | Редактировать товар (только admin) |
| DELETE | destroy.php?id=X | Удалить товар (только admin) |

### Заказы `/api/orders/`

| Метод | Файл | Описание |
|---|---|---|
| GET | index.php | Заказы текущего пользователя |
| POST | store.php | Оформить заказ |

### Администратор `/api/admin/`

| Метод | Файл | Описание |
|---|---|---|
| GET | stats.php | Статистика для дашборда |
| GET | orders.php | Все заказы всех пользователей |
| PUT | order_status.php?id=X | Изменить статус заказа |
| GET | users.php | Список пользователей |
| DELETE | delete_user.php?id=X | Удалить пользователя |

## Калькулятор стоимости (ключевой модуль)

Главная техническая фишка диплома. Интерактивный расчёт без обращения к серверу — всё вычисляется в браузере на JavaScript.

### 6 параметров расчёта

| Шаг | Параметр | Варианты |
|---|---|---|
| 1 | Тип помещения | Квартира (×1.0), Офис (×1.1), Магазин (×1.2), Производство (×1.3) |
| 2 | Площадь | Ползунок 10–300 м² |
| 3 | Тип системы | Сплит, Кассетный, Канальный, Вентиляция |
| 4 | Класс оборудования | Эконом (×0.7), Стандарт (×1.0), Премиум (×1.5) |
| 5 | Количество единиц | Ползунок 1–10 шт |
| 6 | Дополнительные услуги | Монтаж +8 000₽, ТО +3 500₽, Проектирование +15 000₽, Wi-Fi модуль +4 500₽ |

Результат обновляется мгновенно при каждом изменении параметра. Выводится итоговая сумма и диапазон ±15% (минимальная и максимальная оценка).

## Панель администратора

Отдельная страница (`admin.html`) с тёмной темой. Доступ через обычную форму входа: логин `admin`, пароль `admin123`.

### 4 раздела

**Дашборд:**
- 4 карточки статистики: количество товаров, общая выручка, количество заказов, количество пользователей
- График заказов по дням (тип Line — линейный, Chart.js)
- График распределения по категориям (тип Doughnut — пончик, Chart.js)
- Таблица последних заказов

**Каталог:**
- Таблица всех товаров с кнопками Редактировать / Удалить
- Добавление нового товара через модальное окно с формой
- Все изменения мгновенно сохраняются в MySQL и отражаются на сайте

**Заказы:**
- Все заказы всех пользователей
- Смена статуса: Новый → В обработке → Выполнен → Отменён

**Пользователи:**
- Список всех зарегистрированных пользователей
- Удаление пользователя (также удаляет его заказы)

## Личный кабинет пользователя

На странице `account.html` — две части переключаются через JavaScript:
1. **Форма входа/регистрации** — для незарегистрированных посетителей
2. **Личный кабинет** — после авторизации

### Вкладки кабинета

- **Профиль** — редактирование имени и телефона (PUT /api/auth/profile.php)
- **Моя корзина** — содержимое текущей корзины из localStorage
- **История заказов** — все заказы пользователя из MySQL (GET /api/orders/index.php)

---

## Каталог с фильтрами

- Фильтр по категории (табы): Все / Сплит-системы / Кассетные / Канальные / Вентиляция
- Фильтр по цене (поля min / max)
- Фильтр по бренду (чекбоксы): Samsung, Daikin, Mitsubishi Electric, Panasonic, Haier, LG, Ballu, Systemair
- Сортировка: по умолчанию / цена ↑ / цена ↓ / по названию
- Переключение вида отображения: сетка (grid) / список (list)
- Товары загружаются через fetch() из GET /api/products/index.php

---

## Корзина и оформление заказа

- Корзина хранится в localStorage браузера, привязана к конкретному пользователю по ID
- При добавлении товара — Toast-уведомление и обновление счётчика в шапке
- Форма заказа с полями: имя, телефон, email, адрес доставки, комментарий
- Валидация в реальном времени (blur + input события)
- При оформлении — POST /api/orders/store.php → заказ сохраняется в MySQL
- Опционально — отправка уведомления через EmailJS
